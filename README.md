# Early-Z / Overdraw 优化实验

用纯 Python 标准库实现的软件光栅化模拟器，量化 **早 Z（Early-Z）** 与
**先深度后着色（Z-Prepass）** 在不同绘制顺序下的 overdraw 与耗时，
并给出混合透明物体上的失效边界。

## 模拟的三条管线

- `forward_no_early_z`：基线，先跑片元着色器再做深度测试，被遮挡片元也已付出着色成本。
- `forward_early_z`：深度测试通过后才着色；混合透明片元不写深度，必须照常着色与混合。
- `z_prepass`：第一遍只写深度（跳过混合透明物体），第二遍凭深度结果着色，效果与提交顺序无关。

## 指标定义

- 访问片元 / 每像素平均绘制次数：几何覆盖量，只取决于场景，与管线无关。
- 重复绘制像素（着色 overdraw）= 实际着色次数 − 最终覆盖像素，即被浪费的着色工作。
- 每像素平均着色次数：真正反映管线优化效果的 per-pixel overdraw。
- 模型周期：由固定成本模型（深度测试、着色、混合、draw call、pass setup）确定性累加，用于收益排序。
- 墙钟耗时：多次运行取最小值，受 Python 调度噪声影响，仅作参考。

## 复现方式

```bash
python3 -m unittest discover -s tests       # 12 个单元测试
python3 run_benchmark.py                    # 默认 5 次计时，约 1 分钟
python3 run_benchmark.py --repeats 1        # 快速冒烟
```

产物位于 `artifacts/results/`：

- `report.md`：完整 Markdown 报告（参数表、每场景 overdraw 表、着色次数分布、收益排序、结论）。
- `metrics.csv`：全部 7 场景 × 3 管线 × 3 顺序的扁平指标。
- `benefits.csv`：相对无早 Z 基线的下降比例，按模型周期下降排序。
- `boundary_parameters.json`：边界用例输入参数表，seed 固定可完全复现。

## 关键结论

- 大量重叠全不透明场景（E1）：每覆盖像素平均着色次数由 14.97 降到 1.00，重复绘制下降 100%。
- 早 Z 强依赖绘制顺序：前→后提交深度拒绝 889,760 次，后→前为 0；Z-Prepass 对顺序不敏感。
- 透明边界（E3–E6）：混合透明比例 25%→100% 时预通道收益单调缩小；全透明时早 Z 零拒绝，
  Z-Prepass 只剩额外通道开销（模型周期净增 200）。
- 边界反例（E7）：alpha-test 裁剪后存活片元仍写深度，优化收益恢复，
  证明失效边界是“不写深度的混合透明”而非透明度本身。
