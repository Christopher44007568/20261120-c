# 20261120-c — 两级实例化 BVH 基准

## 结构
- `src/math3d.h` — Vec3/Mat4/AABB/Ray/Tri 与求交
- `src/bvh.h` — 通用中位切分 BVH（扁平节点数组 + 统计计数）
- `src/scene.h` — BLAS（每唯一网格一份，实例共享）、TLAS（实例世界包围盒）、
  单层对照场景（每实例三角形烘焙到世界空间）
- `src/main.cpp` — 基准：2 万实例 / 6 唯一网格，正确性校验、帧耗时、
  显存占用、动画更新（只动 TLAS）、单网格多实例场景

## 构建运行
```
g++ -O2 -std=c++17 -o bvh_instancing src/main.cpp && ./bvh_instancing
```

## 结果（2 万实例，34M 三角形等效场景）
| 指标 | 两级实例化 | 单层 BVH |
|---|---|---|
| 节点数 | TLAS 15423 + BLAS 7674（共享） | 18,026,751 |
| 平均节点访问/光线 | 96.0 | 138.1 |
| 平均三角形求交/光线 | 8.7 | 14.7 |
| 单帧耗时 | ~31 ms | ~106 ms |
| 显存占用 | 3.72 MB | 1991.5 MB（535x） |
| 移动 2 万实例 | 4.98 ms，几何重传 0 字节 | 11 s，重传 1173 MB |

结论：相同网格的实例共享 BLAS，变换只更新顶层包围盒，几何数据只上传一次；
求交次数与帧耗时均显著低于单层 BVH，显存峰值低两个数量级以上。
