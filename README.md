# 反射探针视差校正与有机模型四边形重网格化

纯数值实验项目，覆盖四个主题：

1. 反射探针的视差校正（盒形 BPR 与平面投影）及校正前后反射偏移；
2. 相邻探针边界接缝的成因、距离权重混合消除方法，以及探针体积与接缝的关系；
3. 靠墙探针的“反射不穿墙”验证（含故意越界的对照用例）；
4. 有机三角网格重网格化为均匀四边形，并量化均匀性。

## 运行方式

```bash
pip install -r requirements.txt
python3 run_all.py            # 跑全部实验并打印汇总
python3 -m unittest discover  # 单元测试
```

## 核心方法

**盒形视差校正（BPR）**：从着色点 `p` 沿反射方向 `r` 求与探针影响盒
（AABB）的前向交点 `q`，再以探针捕获中心 `c` 为原点用方向 `normalize(q-c)`
采样立方体贴图：

```
t   = 射线 p + t*r 与影响盒的出口距离（slab 法）
q   = p + t*r
dir = normalize(q - c)
```

当影响盒与实际房间几何重合时，`q` 就是真实镜面反射命中点，因此 BPR 的
世界空间偏移与角度误差为 0。平面投影只对单一平面求交，偏离该平面的几何
会产生误差，射线与平面平行或背向时直接失效（数据中记为 `miss`）。

**接缝消除**：硬切换按“最近探针中心”选择，边界两侧方向不连续。重叠区内
改用互补 smoothstep 权重 `w_left + w_right = 1`，权重在重叠面恰好为
0/1，混合方向在物理上连续。是否存在真接缝用细化测试判定：固定物理步长
不断加密采样，真接缝的单步跳变不随步长缩小而消失，连续混合的
`跳变 × 步长` 线性趋于 0。

**不穿墙判据**：墙平面 `n·x = d`，室内满足 `n·x <= d`；反射命中点的
`n·q - d > 0` 即穿透。影响盒贴合墙面时 BPR 命中点恒在盒内，穿透量为 0。

## 主要结论

| 主题 | 结果 |
| --- | --- |
| 校正前角度误差 | 无校正平均约 26°，平面投影平均约 5.7°（且部分射线 miss） |
| 盒形 BPR | 世界偏移 0 m、角度误差 0°（影响盒匹配房间） |
| 硬切换接缝 | 约 71°–72° 方向跳变，细化不收敛，是真不连续 |
| 权重混合 | `跳变×步长` 随细化线性趋于 0，接缝被消除 |
| 靠墙探针 | 全部对抗射线穿透量 0 m；越界 1.5 m 的对照盒稳定穿透 1.5 m |
| 四边形重网格 | 边长 CV 0.081（输入三角 0.103），最大长宽比 1.29，水密 |

**探针体积与接缝的关系**：物理重叠宽度固定时，探针体积越大，重叠占探针
自身尺寸的比例越小，两侧探针的视差差异越大，硬接缝的角度跳变随半边长
近似单调上升（半边长 2→6 m，硬跳变约 49°→85°）。因此接缝治理要保证足够
的**相对重叠比例**并在重叠区内做连续权重混合，而不是单纯增大探针体积。
