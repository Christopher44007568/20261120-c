# 2D SPH 溃坝与皮肤透光验证

这个仓库提供一个可复现的二维 SPH 实验：

- Poly6 核函数计算密度；
- Spiky 核梯度求解密度约束与压力乘子；
- `cKDTree` 邻域搜索；
- PBF-SPH 时间推进，验证溃坝飞溅、撞墙爬升与回流；
- 1k–16k 粒子的邻域搜索耗时扫描；
- 核半径与不可压缩性的量化关系；
- 薄耳与厚脸颊的背光扩散剖面对比。

## 运行

```bash
python3 make_figures.py
```

或：

```bash
bash run_demo.sh
```

## 数值方法

二维 Poly6 密度核：

```text
W(r) = 4/(π h^8) (h²-r²)³,   0 ≤ r < h
ρ_i = m W(0) + Σ_j m W(r_ij),   m = ρ0 dx²
```

Spiky 梯度用于密度约束：

```text
∇W_ij = -30/(π h^5) (h-r)² (x_i-x_j)/r
C_i = max(ρ_i/ρ0 - 1, 0)
λ_i = -C_i / (|∇C_i|² + Σ_j |∇C_ij|² + ε)
Δp_i = -Σ_j (λ_i+λ_j) (m/ρ0) ∇W_ij
```

`λ` 是密度约束的压力乘子；诊断用的 Tait 压力为

```text
P_i = B[(ρ_i/ρ0)^γ - 1],  B = ρ0 c0²/γ
```

这样压力来自核梯度，同时避免弱可压缩 SPH 在强冲击下产生的密度尖峰。
邻域查询使用 `scipy.spatial.cKDTree`，复杂度接近 `O(N log N)`。

## 邻域搜索标度

固定 h/dx 与粒子密度，单纯改变粒子数。下表为单线程 CPU 时间，
避免共享机器上的后台负载污染算法指标：

| 粒子数 | 中位耗时 | p95 |
|---:|---:|---:|
| 1,000 | 0.649 ms | 0.813 ms |
| 2,000 | 1.433 ms | 1.555 ms |
| 4,000 | 3.192 ms | 3.930 ms |
| 8,000 | 7.038 ms | 8.748 ms |
| 16,000 | 15.007 ms | 16.248 ms |

对数拟合得到 `t ∝ N^1.14`，接近线性；每粒子成本约 0.65–0.94 µs。
16k 粒子约 15 ms/step，邻域搜索随粒子数可控增长。

## 核半径与不可压缩性

二维中邻居数近似为：

```text
N_neighbor ≈ π (h/dx)²
```

因此增大 h 会让核估计更平滑、密度约束残差更小，但邻域量按 h² 增长：

| h/dx | 平均邻居数 | p99 压缩均值 | 搜索耗时 |
|---:|---:|---:|---:|
| 2.4 | 16.0 | 0.5838% | 0.53 ms |
| 2.8 | 19.2 | 0.4627% | 0.65 ms |
| 3.2 | 25.0 | 0.3586% | 0.75 ms |
| 3.6 | 33.0 | 0.2428% | 0.83 ms |
| 4.0 | 38.0 | 0.1797% | 0.85 ms |
| 4.4 | 47.0 | 0.1221% | 0.98 ms |

结论：在粒子间距固定时，p99 密度压缩随 h/dx 单调下降，说明不可压缩性改善；
但搜索耗时随 h² 上升。工程折中取 `h/dx ≈ 3.4–4.0`。若需要进一步提高不可压缩性，
优先增加 PBF 约束迭代次数，而不是无限增大核半径。

## 皮肤透光对比

透光模型由 Beer–Lambert 厚度衰减与随厚度变化的扩散核组成：

```text
T(x) = exp(-μ_t d(x))
I_d(x) = G_σ(x) * [S(x) T(x)]
```

薄耳厚度取 0.7–2.3 mm，厚脸颊取 2.8–8.2 mm。实测径向扩散剖面：

| 区域 | HWHM | 扩散长度 | 单调性 | 拟合残差 |
|---|---:|---:|---:|---:|
| 薄耳 | 64 px | 76.0 px | 100% | 7e-5 |
| 厚脸颊 | 42 px | 48.9 px | 100% | 1.9e-4 |

薄组织形成更宽、更偏红的透光晕；厚组织吸收更强、扩散更窄。两条剖面的
stretched-exponential 拟合指数均约 2.0，符合扩散主导的高斯型衰减，且无阶跃。
