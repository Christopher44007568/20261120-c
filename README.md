# HULL / DUAL

三维凸包、Delaunay 四面体剖分、共面/共球退化处理与阴影体封帽审计台。纯 JavaScript 实现，无运行时依赖；浏览器端使用 Canvas2D 透视投影展示网格和相机穿越阴影体的过程。

![审计台预览](./artifacts/preview.png)

## 运行

```bash
npm start
# http://127.0.0.1:4173

npm test
npm run report
```

`npm test` 对五组固定点集与 100 组确定随机点集执行拓扑回归。`npm run report` 重新生成：

- `artifacts/validation-report.json`
- `artifacts/validation-report.md`

## 实现

- `src/hull.js`：增量三维凸包。可见面删除后用方向边提取空腔边界，新增面统一由初始四面体内点校正为外法向。
- `src/delaunay.js`：Bowyer–Watson 四面体剖分。检查空球条件、删除可见四面体，再从空腔边界向插入点连成新四面体。
- `src/coplanar.js`：内在维数为 2 时，先投影到平面做二维 Delaunay，再在法向两侧添加两个合成支撑点，输出封闭双锥四面体网格。
- `src/validate.js`：边/面入射、定向一致性、Euler 特征、连通分量、体积守恒、空球条件、共面簇和共球命中统计。
- `src/shadow.js`：受光面近端帽、背面平移远端帽、轮廓边扫掠侧面；对封闭体做边流形、定向、Euler 和体积审计。
- `src/renderer.js` / `src/app.js`：交互视图、案例切换、穿越回放、模板计数与 JSON 导出。

## 五组点集结果

`V` 为含合成支撑点的网格顶点数，`E` 为四面体无向边数，`F` 为凸包三角面数，`T` 为四面体数，`χ` 为凸包 Euler 特征。

| 点集 | 路径 | V | E | F | T | χ | 凸包 | 四面体拓扑 | 体积相对误差 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- | --- | ---: |
| 随机点集 | 3D Bowyer–Watson | 46 | 246 | 54 | 174 | 2 | 封闭 | 流形一致 | 1.05e−15 |
| 全共面点集 | 2D Delaunay + 双支撑 | 42 | 186 | 22 | 134 | 2 | 封闭 | 流形一致 | 2.12e−16 |
| 全共球点集 | 3D Bowyer–Watson | 38 | 159 | 72 | 86 | 2 | 封闭 | 流形一致 | 1.98e−16 |
| 共面 + 共球混合 | 3D Bowyer–Watson | 51 | 277 | 56 | 199 | 2 | 封闭 | 流形一致 | 1.52e−16 |
| 补充退化点集 | 3D Bowyer–Watson | 74 | 378 | 102 | 254 | 2 | 封闭 | 流形一致 | 1.78e−16 |

额外凸包计数：

| 点集 | 凸包顶点 | 凸包边 | 凸包面 | 四面体边 |
| --- | ---: | ---: | ---: | ---: |
| 随机点集 | 29 | 81 | 54 | 246 |
| 全共面点集 | 13 | 33 | 22 | 186 |
| 全共球点集 | 38 | 108 | 72 | 159 |
| 共面 + 共球混合 | 30 | 84 | 56 | 277 |
| 补充退化点集 | 53 | 153 | 102 | 378 |

五组案例均满足：

- 每条凸包无向边恰好入射 2 个三角面，定向边各出现 1 次。
- 凸包 `V - E + F = 2`。
- 四面体内部面恰好入射 2 个单元，边界流形连通且 `χ = 2`。
- 所有四面体体积为正，总计体积与凸包体积一致。
- 每个四面体的空球内不含其他输入点。
- 四面体边界三角面数与凸包面数一致。

## 退化策略与计数

| 点集 | 内在维数 | 重复点 | 极大共面簇 | 最大共面点数 | 共球空球命中 | 退化四面体 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 随机点集 | 3D | 0 | 0 | 0 | 0 | 0 |
| 全共面点集 | 2D | 0 | 1 | 40 | 96 | 0 |
| 全共球点集 | 3D | 0 | 0 | 0 | 2924 | 0 |
| 共面 + 共球混合 | 3D | 0 | 1 | 21 | 518 | 0 |
| 补充退化点集 | 3D | 3 | 5 | 21 | 818 | 0 |

处理顺序：

1. **合并重复点**：按包围盒尺度的 `1e-9` 容差去重，并保留源点索引。
2. **共面降维**：内在维数 2 时投影到平面，做二维 Delaunay；添加法向两侧两个合成支撑点形成双锥体，合成点计入 `V` 并单独标记。
3. **共球符号扰动**：三维谓词使用确定性的有界正则化坐标打破空球平局；最大位移约为包围盒尺度的 `1e-7` 量级。源坐标仍用于共面簇和空球命中统计。
4. **拒绝零体积单元**：输出与审计只接受正体积四面体。五组案例的 `degenerateTetsRemoved` 均为 0。

“极大共面簇”统计至少 8 个点共享、且不被更大共面簇包含的平面；“共球空球命中”统计最终四面体空球边界上的非顶点源点数量。

## 阴影体封帽与模板翻转

阴影体由三部分组成：

- 近端帽：朝向光源的凸包三角面。
- 远端帽：背向光源的凸包三角面沿光线方向平移。
- 侧面：受光面与背面之间的轮廓边沿光线扫掠形成的四边形。

封帽审计要求边入射全部为 2、定向边全部为 1、Euler 特征为 2 且体积为正。相机从光源一侧沿光线穿过体，模板计数定义为“外侧 0 / 内侧 1”。五组记录均为：

```text
随机点集        near-cap t=0.2366  0 -> 1 ; far-cap t=0.7619  1 -> 0 ; final 0
全共面点集      near-cap t=0.2703  0 -> 1 ; far-cap t=0.7461  1 -> 0 ; final 0
全共球点集      near-cap t=0.2346  0 -> 1 ; far-cap t=0.7713  1 -> 0 ; final 0
共面 + 共球混合 near-cap t=0.2379  0 -> 1 ; far-cap t=0.7708  1 -> 0 ; final 0
补充退化点集    near-cap t=0.2370  0 -> 1 ; far-cap t=0.7736  1 -> 0 ; final 0
```

进入近端帽 `+1`、离开远端帽 `−1`，最终回到 0，说明双端封帽完整；若省略近端帽，相机进入阴影体后模板计数会保持相反符号，无法在离开时正确归零。

## 界面

- 五个数据页签可切换随机、全共面、全共球及两组混合退化点集。
- `凸包`、`四面体`、`阴影体` 三种显示模式。
- 拖拽旋转、滚轮缩放、双击复位。
- 点击穿越面板播放按钮，可观察相机沿光线移动时模板计数 `0 → 1 → 0`。
- `导出 JSON` 输出当前五组案例的完整审计记录。

字体使用仓库内打包的 Noto Sans SC 子集，许可证见 `assets/fonts/OFL.txt`。
