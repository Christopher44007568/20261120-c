# FORMA / 形变与光学

一个无构建依赖的计算材料实验台：左侧是位置动力学（PBD）软体求解，中段是挤压/拉伸体积与稳定性验证，底部是多层车漆的逐波长能量与颜色分析。

## 运行

```bash
npm start
# http://127.0.0.1:8080
```

重新生成命令行验证结果与 `artifacts/validation-report.json`：

```bash
npm run validate
```

## 软体求解

- 125 粒子实时网格，13 邻域距离约束维持局部结构。
- 上下压板作为运动学边界，球体探针使用 PBD 投影处理接触与穿透。
- 全局横截面体积约束补偿单轴挤压/拉伸造成的等容偏差。
- 二阶子步、速度回写、阻尼与弱形状正则化抑制高频振荡。
- 页面实时显示体积保持率、顶点位置误差、残余抖动、迭代次数与求解残差。

## 挤压 / 拉伸验证

固定形变 18%、刚度 0.82、同一组 3 个扰动种子，仅改变约束迭代次数。每个案例运行 60 步；顶点误差定义为相对 64 次迭代参考解的首帧 RMS 顶点距离，抖动取加载窗口内的峰值残余速度。

| 迭代 | 挤压体积 | 拉伸体积 | 顶点误差 | 抖动 | 稳定性 | 结论 |
| ---: | ---: | ---: | ---: | ---: | ---: | :--- |
| 1× | 99.508% | 100.165% | 1.495 mm | 5.035 | 64.0 | ITERATE |
| 2× | 99.508% | 100.165% | 0.880 mm | 2.676 | 80.0 | ITERATE |
| 4× | 99.508% | 100.165% | 0.551 mm | 1.382 | 88.7 | PASS |
| 8× | 99.508% | 100.165% | 0.341 mm | 0.626 | 93.9 | PASS |
| 16× | 99.508% | 100.165% | 0.186 mm | 0.362 | 96.0 | PASS |
| 32× | 99.508% | 100.165% | 0.084 mm | 0.291 | 96.7 | PASS |
| 64× | 99.508% | 100.165% | 0.000 mm | 0.221 | 97.4 | PASS |

结论：两种形变下体积误差均小于 0.5%；迭代从 1 增加到 64 时，残余抖动下降 95.6%，位置误差收敛到 0。4× 后进入稳定区，8× 后提升趋缓，32× 后进入平台，因此继续增加迭代的收益递减。

## 车漆光学

清漆、金属底色、底漆与基材四层采用非相干光谱传输：

- 清漆表面使用角度相关菲涅耳反射。
- 清漆内部进行 12 次往返，累计金属底色反射、吸收与底漆透射。
- 清漆和底漆使用 Beer–Lambert 衰减。
- 逐波长计算 `R(λ) + T(λ) + A(λ) = 1`。
- 用 CIE 1931 近似匹配函数生成 0–75° 视角颜色曲线与色样。

三种车漆在 35° 的广谱能量审计：

| 车漆 | R | T | A | 总能量 | 最大残差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Cobalt Flux | 25.37% | 2.40% | 72.23% | 100.000000% | 4.44e−16 |
| Ember Phase | 34.29% | 2.07% | 63.64% | 100.000000% | 4.44e−16 |
| Titan Silver | 54.95% | 1.32% | 43.73% | 100.000000% | 4.44e−16 |

## 文件

- `index.html` / `styles.css`：实验台界面与响应式布局。
- `src/sim.js`：PBD 求解器、体积校正、验证扫描。
- `src/paint.js`：多层光谱传输、CIE 颜色计算。
- `src/charts.js`：曲线与漆面截面绘制。
- `src/main.js`：交互、动画、指标与 JSON 导出。
- `scripts/validate.mjs`：可重复的命令行验证。
