# 透明渲染对照器：交错薄片与玻璃壳

面向**交错薄片（zero-thickness sheets）与玻璃壳（glass shells）**的透明渲染教学/验证工具。
核心对比两条合成路径，并以 CPU 逐片元排序结果作为像素级参考真值：

- **双深度剥离（Dual Depth Peeling, DDP）**：每轮同时剥离最近与最远的剩余片元，
  前目标用预乘 `over` 累积、后目标用预乘 `under` 累积，预算耗尽时未处理片元被显式丢弃。
- **CPU 参考**：对每个像素的全部片元按相机空间深度排序，统一使用预乘透明度 `over` 合成。
- **乱序单趟混合**：按被打乱的物体提交顺序直接 `over`，复现传统 alpha 混合的顺序依赖错误。

三条路径共享同一套片元数据与同一套预乘规则，因此差异只来自“顺序/剥离逻辑”本身。

## 运行

无构建步骤、无第三方依赖，直接打开 `index.html` 即可；也可启动本地服务：

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
npm test                      # Node 不变量测试（无需浏览器）
npm run snapshots             # 生成 PPM/PNG 像素快照到 test/snapshots
```

## 界面与交互

六联画布：

1. **CPU 参考** — 逐片元深度排序 + 预乘 over（拖拽此画布旋转相机，滚轮缩放）。
2. **双深度剥离** — 前/后双目标分离累积，受剥离轮数预算限制。
3. **乱序单趟混合** — 传统错误对照，随物体顺序变化而变色。
4. **像素误差热力图** — DDP 与参考的 RGB 欧氏距离，蓝→红表示误差增大。
5. **未处理片元遮罩** — 预算不足时仍有片元被丢弃的像素，纯红标出并计数。
6. **预算 / 最先失真图** — 每像素精确合成所需剥离轮数；当前预算下会失真的像素标红，
   红色越亮表示在越早的轮数就开始失真。

控制面板：

- 三组模型：`occluder`（不透明遮挡物 + 交错透明层）、`intersect`（相交面互穿）、
  `coplanar`（7 层近共面薄片 + 掠射玻璃壳，单像素最多 8 层）。
- 剥离轮数预算 1–8，分辨率 120/180/240。
- 透明物体顺序：原始 / 逆序交换 / 随机打乱（重复点击更换随机种子）。
- 顶部状态条在预算充足时显示绿色“预算充足”，不足时变红并报告丢弃片元的像素数量。

## 合成数学（统一预乘透明度）

片元颜色 `(r,g,b,a)` 先转预乘 `(ra, ga, ba, a)`。

- 前目标（近→远，`src over dst`）：
  `rgb' = src.rgb + dst.rgb·(1-src.a)`，`a' = src.a + dst.a·(1-src.a)`
- 后目标（远→近，`dst under src`）：
  `rgb' = dst.rgb + src.rgb·(1-dst.a)`，`a' = dst.a + src.a·(1-dst.a)`
- 最终帧缓冲：`opaqueBase ⟨over⟩ front ⟨over⟩ back`

预算为 `k` 轮时，每像素至多处理 `2k` 层；超出部分计入 `leftoverMask` 并在界面明确标红。

## 代码结构

- `src/math.js` — 向量/矩阵、透视投影、轨道相机。
- `src/geometry.js` — 程序化玻璃壳（六面立方体）、双面薄片与三组场景。
- `src/rasterizer.js` — 近/远平面 Sutherland–Hodgman 裁剪、边函数扫描、
  透视校正深度、不透明深度测试与每像素片元列表。
- `src/compositor.js` — 预乘 over/under、参考排序、DDP 逐像素模拟、乱序混合与误差统计。
- `src/visualization.js` — 画布 blit、误差热力图、损失遮罩、预算图配色。
- `src/app.js` — UI 状态、顺序置换、相机交互与重绘调度。
- `test/smoke.js` — over/under 互逆、全预算 DDP 恒等于参考、欠预算丢片元。
- `test/invariance.js` — 顺序无关性、移动相机一致性、损失遮罩与真实失真逐像素一致、
  最小精确预算预测。
- `test/snapshots.js` / `test/ppm2png.py` — 离线像素快照与无依赖 PPM→PNG 转换。

## 验证结论（`npm test` 覆盖）

- 预算覆盖最深像素时，DDP 与参考逐像素误差为 0，且与透明物体提交顺序、相机位姿无关。
- 乱序单趟混合在交换/打乱顺序后颜色发生变化（顺序依赖），作为错误对照稳定复现。
- 预算不足时，被标记“仍有未处理片元”的像素集合与实际颜色失真像素集合完全一致，
  并由预算图指出最先失真的区域。
