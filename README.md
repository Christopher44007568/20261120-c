# 沿法线网格偏移与壳化

该项目对闭合三角网格做角度加权法线偏移，在有符号距离场（SDF）上提取
`±d` 等距面，并用 Manifold 布尔差生成壳体。流程会统计原始偏移中的
三角形自交、自动收紧简化容差、验证最终内外表面连续性，并输出不同偏移
距离下的三角形数和体积变化。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 scripts/run_study.py
```

默认使用带 4 个圆柱通孔的闭合平板：

- 尺寸 `6.2 × 4.6 × 1.4`
- 通孔半径 `0.5`
- 偏移距离 `0.12, 0.20, 0.28, 0.36`
- SDF 分辨率 `0.09`

也可以输入自己的水密 OBJ/STL/PLY：

```bash
python3 scripts/run_study.py \
  --input model.obj \
  --distances 0.1 0.2 0.3 \
  --resolution 0.08 \
  --out artifacts
```

输入可以是带通孔的闭合网格；开放边界网格需要先封口。输出包括：

- `artifacts/REPORT.md`：中文验证报告和结果表
- `artifacts/summary.json`：完整机器可读结果
- `artifacts/summary.csv`：逐距离汇总
- `artifacts/meshes/*.obj`：原始模型和每个距离的壳体

运行测试：

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 默认结果

原始模型为 1052 个三角形、亏格 4、体积 `35.536829`。

| 距离 | 原始偏移自交 | 最终壳自交 | 壳体三角形 | 壳体积 | 体积变化 |
|---:|---:|---:|---:|---:|---:|
| 0.120 | 2 | 0 | 20286 | 23.443413 | -12.093416 |
| 0.200 | 2 | 0 | 23624 | 38.629551 | +3.092721 |
| 0.280 | 6 | 0 | 32448 | 53.397194 | +17.860364 |
| 0.360 | 10 | 0 | 23590 | 67.640344 | +32.103514 |

四个距离均满足：外、内表面各 1 个连通分量，亏格均为 4，边界边和非流形边
均为 0，壳面为 2 个水密表面分量，最终自交为 0。因此自交修复后内外表面
连续，壳面完整。

## 方法

1. 用面法线和顶点夹角计算角度加权顶点法线，得到原始 `v ± d·n` 偏移。
2. 对原始内外偏移做非退化三角形自交检测，记录待修复对数。
3. 在网格 SDF 上提取 `+d` / `-d` 等值面。SDF 会自然闭合尖锐角并消除
   自交；凸尖角变为半径 `d` 的圆角，凹角被正确裁剪。
4. 若简化后的壳面仍有几何自交，自动将简化容差减半后重建。
5. 用 `outer - inner` 生成壳体，并验证：
   - Manifold 状态为 `NoError`
   - 外、内表面闭合、单连通、亏格一致
   - 壳体有外、内两个水密表面分量
   - 边界边、非流形边和最终自交均为 0
   - `壳体积 = 外表面体积 - 内腔体积`

体积变化定义为 `壳体积 - 原始体积`。负值表示移除的内腔大于向外增长的
材料；距离增大到一定程度后，外部增长占优。
