# Field Type Lab

供地图标注检查的 WebGL2 多通道有符号距离场（MSDF）字形诊断台。项目为零构建静态应用，字体解析器、OpenType.js 与界面字体子集均已本地化，不上传本地字体。

## 运行

```bash
cd /home/hj/userfeedback2/uid5-0020
python3 -m http.server 4180
```

打开 `http://127.0.0.1:4180/`。应用使用 ES Modules，因此需要通过 HTTP 服务打开，不能直接双击 `index.html`。

## 功能

- 内置 6 组可复用测试轮廓：锐角与三角负空间 `A`、内孔与相邻曲线 `O`、hairline 细笔画 `i`、双内孔窄腰 `8`、锐角楔形 `K`、刻意开放轮廓 `S*`。
- 导入本地 TTF / OTF / WOFF 字体，输入任意字符后生成独立测试字形。
- 自动展平贝塞尔曲线，按尖角阈值拆分边，并为每组边分配 RGB 通道；A 通道同时保存单通道 SDF。
- WebGL2 中按屏幕导数重建覆盖率，支持 MSDF 覆盖率、单通道 SDF、原始距离场、精确轮廓参考与误差叠加。
- 显示测试字号下的采样网格、尖角、内孔、开放端点和结构注释。
- 4 档字号 × 4 个亚像素位置扫描，逐格输出边界偏差与断笔像素数，并可导出 CSV。
- 自动区分轮廓拓扑错误与着色/采样误差，并分别给出画布标记和判读文案。

## 诊断口径

- **边界偏差**：参考边界带内被错误分类的像素，其到真实轮廓的有符号平均距离。正值为外扩，负值为内缩。
- **平均边界距离 / P95**：错分像素到高分辨率参考轮廓的绝对距离，分别反映平均偏差和长尾。
- **断笔像素**：参考覆盖率至少 82%，但 MSDF 重建覆盖率低于 35% 的像素。
- **边界错分**：当前字号下内外分类与参考覆盖率不一致的像素数；该计数随轮廓周长增长，判断质量时应结合平均距离与 P95。
- **轮廓错误特征**：参考视图中已存在破口、自交或重复顶点，并在所有字号下保持一致。
- **着色采样误差特征**：轮廓参考干净，但角点圆化、细笔画丢失、通道接缝或覆盖率随字号/亚像素位置漂移。

## 结构

- `src/contours.js`：路径解析、轮廓归一化。
- `src/geometry.js`：自适应贝塞尔展平、尖角检测、边分组、拓扑检查。
- `src/msdf.js`：距离纹理生成与 CPU 侧双线性重建。
- `src/renderer.js`：WebGL2 着色与导数覆盖率。
- `src/evaluate.js`：高分辨率 Canvas 参考与逐像素指标。
- `src/main.js`：界面状态、扫描、字体导入与叠加标记。

界面字体使用 Noto Sans SC / Noto Serif SC 的本地 WOFF2 子集，许可见 `vendor/NOTO-LICENSE`；OpenType.js 许可见 `vendor/OPENTYPE-LICENSE`。
