# HZB 遮挡剔除与无散度湍流验证

这是一个可直接运行、可复现的 OpenGL 4.5 基准：

- 从上一帧深度构建 mip 金字塔（逐级 2x2 max）。
- 在 compute shader 中用 HZB 批量测试物体 AABB。
- 用每物体一个 `GL_ANY_SAMPLES_PASSED` 查询作为逐物体遮挡基线。
- 在 227 个建筑/家具盒体和 936 个待测物体的密集室内场景中统计剔除率、
  每帧测试数、精度、误剔除率和耗时。
- 用无散度 ABC 流推进 16384 个粒子，验证体积保持场不会让粒子聚集。

当前容器没有物理 GPU，程序通过 Mesa `llvmpipe` 执行真实的 OpenGL 4.5
compute/query 路径。下面的绝对耗时是软件渲染结果；硬件 GPU 的绝对值会不同，
但测试口径和算法一致。

## 构建与运行

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/hzb_cull --frames 7 --assert
```

可用参数：

- `--frames N`：计时帧数，默认 7；每帧取中位数。
- `--assert`：任一精度、加速比、剔除率、散度或聚集指标不达标时返回非零。

`ctest --test-dir build --output-on-failure` 会运行同一套阈值检查。

## 基准口径

1. 以当前相机渲染一张 24-bit 深度图，作为“上一帧深度”。
2. 深度图复制到 R32F level 0，再由 GPU compute shader 逐级写入 2x2 max mip。
3. 每个物体 AABB 投影到屏幕，选择能覆盖其屏幕包围矩形的 mip；
   仅当 AABB 最近深度大于覆盖 tile 的最大遮挡深度时剔除。
4. 基线对每个物体提交一次深度测试绘制和一个遮挡查询，再读取全部查询结果。
5. HZB 与查询计时均不含深度预通道：HZB 包含金字塔构建、单次 compute dispatch
   和结果回读；查询包含 936 次绘制/查询和结果回读。两者前后都调用 `glFinish()`。

精度定义：

- 精度 = HZB 剔除且实际不可见的物体数 / HZB 全部剔除数。
- 误剔除率 = 实际可见但被 HZB 剔除的物体数 / 实际可见物体数。
- 每帧测试数：936 个 AABB 测试、1 次 HZB dispatch；基线为 936 个查询。

## 实测结果

环境：`llvmpipe (LLVM 21.1.8, 256 bits)`，Mesa 26.0.8，7 帧中位数。

| Z 分辨率 | HZB ms | 查询 ms | 加速 | 剔除率 | 精度 | 误剔除率 |
|---:|---:|---:|---:|---:|---:|---:|
| 1280x720 | 2.127 | 4.343 | 2.04x | 86.75% | 100.00% | 0.00% |
| 960x540 | 1.488 | 2.945 | 1.98x | 86.86% | 100.00% | 0.00% |
| 640x360 | 1.069 | 1.999 | 1.87x | 86.54% | 100.00% | 0.00% |
| 480x270 | 0.911 | 2.017 | 2.21x | 86.86% | 100.00% | 0.00% |
| 320x180 | 0.940 | 1.808 | 1.92x | 86.00% | 100.00% | 0.00% |
| 160x90 | 0.659 | 1.582 | 2.40x | 85.58% | 100.00% | 0.00% |

1280x720 下每帧执行 936 个 AABB 测试，仅需 1 次 HZB compute dispatch，
相对 936 次逐物体查询约快 2.0 倍。密集场景的精确遮挡率为 95.94%，
HZB 召回率为 90.42%，其余为保守漏剔，没有可见物体被误剔。

降低 Z 分辨率只会让 mip tile 变大：只有更大的 tile 内最大深度仍近于物体时
才会剔除，因此会减少剔除数量但不会破坏保守性。实测从 1280x720 降到 160x90
时剔除率从 86.75% 降到 85.58%，召回率从 90.42% 降到 89.10%，精度始终保持
100%，误剔除率始终为 0%。结论是低分辨率带来可控的保守漏剔，而非错误剔除。

## 湍流验证

速度场为周期域 ABC 流：

```text
u = A sin(z + wt) + C cos(y)
v = B sin(x + wt) + A cos(z)
w = C sin(y + wt) + B cos(x)
```

每个分量对其自身坐标的偏导为零，所以解析散度为 0。使用 RK4、`dt=0.008`
推进 16384 个粒子 600 步，并用空间哈希统计最近邻距离及 19x19x19 网格占据度：

| 指标 | 初始 | 结束 | 比值 |
|---|---:|---:|---:|
| 平均最近邻距离 | 0.136654 | 0.136551 | 0.999247 |
| 占据度 CV | 0.651545 | 0.643495 | 0.987645 |

有限差分散度平均值和最大值均为 0；最近邻距离保持率约 0.999，密度 CV 没有增长，
说明无散度场没有出现塌缩或聚集。64 条代表性轨迹见
`artifacts/turbulence_trajectories.svg`。
