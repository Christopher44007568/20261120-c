# 20261120-c

CPU 实现的粒子拖尾条带渲染与材质图工具集（C++17，无外部依赖）。

## 构建与运行

```bash
make          # -std=c++17 -O2 -Wall -Wextra -Wpedantic -Wshadow -Wconversion
make run      # 构建并运行全部 7 组验证
```

可执行文件输出到 `build/trail_demo`，渲染图输出到 `artifacts/`（PPM 与 PNG）。

## 模块

- `src/trail.h` / `src/trail.cpp`：环形历史缓冲、miter 条带生成、宽度与透明度衰减、绘制统计。
- `src/rasterizer.h` / `src/rasterizer.cpp`：RGBA 帧缓冲、重心坐标光栅化、straight-alpha over 混合、PPM 输出。
- `src/material_graph.h` / `src/material_graph.cpp`：材质图节点/边、死节点反向可达性清理、Kahn 拓扑排序与环检测。
- `src/main.cpp`：7 组自动化验证与演示渲染。

## 条带构建规则

- 每个历史点生成左右两个环顶点，稳态顶点数 = `粒子数 * 2 * 历史缓冲长度 H`。
- 相邻环之间生成一个四边形（2 个三角形，6 个索引），相邻四边形共享整环顶点，无 T 形接缝。
- 宽度按 `tailWidth -> headWidth` 线性插值，alpha 按 `tailAlpha -> headAlpha` 线性插值。
- 拐角使用 miter join，miter 长度按 `1/sin(theta/2)` 计算并受 `miterLimit` 钳制；
  被钳制的拐角额外插入中心点扇形三角形，消除楔形缺口，保证条带水密。
- 混合采用 straight-alpha over 合成：
  `outA = srcA + dstA*(1-srcA)`，
  `outRGB = (srcRGB*srcA + dstRGB*dstA*(1-srcA)) / outA`。

## 验证结论（程序实跑输出）

### 快速移动粒子拖尾连续性（34 px/帧，H=24）

- 24 个历史点 => 48 个条带顶点，23 个四边形 => 46 个三角形、138 个索引。
- 逐列覆盖扫描确认 34 px 大步长之间没有任何透明列，条带全程连续。
- 单粒子：每粒子 1 个批次，合并索引缓冲后 1 个批次。

### 宽度衰减与半透明混合

- 尾环宽度 = `tailWidth`、头环宽度 = `headWidth`，逐环单调；尾/头 alpha 与配置一致。
- 单次混合精确匹配 `src*a + dst*(1-a)`；两层 0.4 alpha 叠加得到 0.64。
- 两条 50% 透明度条带交叉区域 alpha 升至 75%，确认是叠加而非替换。

### 顶点数与绘制批次（3 粒子，H=10）

- 条带顶点 60（= 3 * 2 * 10），三角形 54，索引 162。
- 逐粒子提交 = 3 个绘制批次；合并为单个索引缓冲后 = 1 个批次。

### 历史缓冲长度对拖尾形态的影响

| H | 条带顶点 | 三角形 | 拖尾长度 (px) | 形态 |
|---|----------|--------|----------------|------|
| 4 | 8 | 6 | 30 | 短而紧凑，仅保留最近轨迹 |
| 8 | 16 | 14 | 70 | 中等长度 |
| 16 | 32 | 30 | 150 | 长拖尾，运动历史更完整 |
| 32 | 64 | 62 | 310 | 最长，覆盖半个屏幕，顶点/带宽成本翻倍 |

结论：H 同时决定拖尾时间跨度与几何成本，顶点数严格为 `2H`（被钳制拐角另有少量扇形中心点）。
H 越大拖尾越长、越平滑，但顶点处理与混合填充率线性上升；H 过小则高速运动时拖尾变成离散短段。

### 材质图：死节点清理与拓扑排序

- 8 节点图中 2 个不可达 Output 的节点（孤立常量与孤立数学节点）及其边被清除，保留 6 节点 5 边。
- Kahn 拓扑排序保证每条边的源节点排在目标节点之前，Output 节点位于序列末尾，可直接驱动着色器代码生成顺序。
- 含环图排序失败并报告全部不可调度节点；环上节点因仍可达 Output 不会被误清理。
