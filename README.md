# 噪声形态实验室

Perlin、Worley 与 Simplex 的 WebGL2 程序化噪声对照实验。三种基元共享坐标、八度、增益、缩放、种子与域扭曲参数，分别映射到云、石纹与扰动三种材质。

## 运行

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。页面只依赖 WebGL2 与原生 ES modules，不需要构建步骤。

## 实验内容

- **九宫格主视图**：三列依次为 Perlin、Worley、Simplex，三行依次为云、石纹、扰动。
- **分形叠加**：3–7 个八度，每层旋转并采用 2.03 的 lacunarity。
- **域扭曲**：由同种噪声生成两轴低频偏移场，再对主 fBm 采样坐标做平滑位移。
- **频谱**：从 GPU 读回 256² 标量场，应用 Hann 窗和二维 FFT，输出对数频率轴上的径向平均功率谱。
- **各向异性**：结构张量相干度 `sqrt((Jxx-Jyy)² + 4Jxy²) / (Jxx+Jyy)`，同时绘制梯度能量角分布。
- **细节增益**：域扭曲场与未扭曲场的梯度 RMS 相对变化。
- **伪影审计**：检查高频段径向谱相对局部趋势的最大突出量；越接近 1 表示越平滑。
- **生成耗时**：512² 全屏片元着色器的 4 次 GPU 计时查询中位数；不支持计时扩展时回退到同步采样。分别记录域扭曲开/关成本。

## 输出

`SNAPSHOT` 下载九宫格 PNG，`REPORT` 下载包含参数、耗时、频谱与各向异性的 JSON 报告。所有分析结果都在当前参数改变后重新计算。

无头测试环境使用 SwiftShader 时，绝对耗时会明显高于硬件 GPU；同一次会话中的相对成本和频谱形状仍可直接比较。
