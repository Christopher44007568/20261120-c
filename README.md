# DQS / LBS 实时蒙皮实验台

浏览器内运行的双四元数蒙皮（DQS）与传统线性混合蒙皮（LBS）对照。两条路径共用绑定姿态、关节变换、骨架和顶点权重；支持同一旋转的 `+q` / `-q` 输入，以及权重和为零的孤立顶点。

## 运行

```bash
npm start
```

打开终端输出中的地址（默认 <http://127.0.0.1:4173>；端口占用时会自动顺延）。页面不需要构建步骤或第三方运行时依赖。

```bash
npm test       # 纯数学与蒙皮回归测试
npm run verify # 重新生成 artifacts/verification.json
```

## 交互

- `分节圆柱 / 肘关节`：切换程序化生成的测试模型。
- `LBS / DQS / 误差热图`：切换渲染路径；热图显示同一顶点在两算法下的三维距离。
- 角度滑杆与播放键：`0° → 180°` 扫描。
- 四元数符号按钮：把当前关节输入从 `+q` 改为 `-q`，物理旋转不变。
- 拖拽、滚轮、双击：旋转、缩放、复位相机。

## 实现要点

- DQS 使用齐次双四元数混合后归一化实部并同步缩放对偶部；零权重和直接回退到绑定位置。
- 每根骨骼的输入四元数在着色前进行半球对齐：首帧使用确定性规范符号，之后与上一帧对齐，因此同一旋转的 `+q` / `-q` 不会引起闪跳。
- GPU 顶点着色器同时计算 LBS 与 DQS，按模式选择结果并输出逐顶点误差；CPU 的同一套公式用于截面积、轨迹和测试。
- 权重混合区间由共享平滑阶梯权重定义：`z=1` 到 `z=3`。区间外为刚体区域；区间内 LBS 在极限角度产生截面收缩，DQS 保持截面。

## 验证结果

验证脚本以 1° 步长覆盖 `0°–180°`，并对两个模型执行同一组断言：

- 绑定姿态与输入模型的最大偏差：LBS `0.0e+0`，DQS `0.0e+0`。
- 同一旋转的 `+q / -q` 最大顶点跳变：`0.0e+0`。
- 3 个 `wSum = 0` 孤立顶点在所有角度保持绑定位置，偏差 `0.0e+0`。
- `180°` 时中段截面积：扭转圆柱 LBS `0.00%`、DQS `100.00%`；肘关节 LBS `0.00%`、DQS `100.00%`。

完整数据写入 `artifacts/verification.json`。界面截图位于 `artifacts/figures/app_*.png`。

## 场景与算法

- 扭转圆柱：两骨骼沿 `Z` 轴扭转，权重在 `z=1–3` 平滑过渡；探针环位于 `z=2`。
- 肘关节：同一拓扑绕 `X` 轴在 `z=2` 的关节处弯曲，展示关节内外侧的截面塌缩与保形差异。
- `LBS`：按权重混合 `world * inverseBind` 矩阵。
- `DQS`：按权重混合单位双四元数，归一化实部并同步缩放对偶部，再用其旋转/平移顶点。
- `误差热图`：逐顶点显示 `||DQS(p) - LBS(p)||`，固定色标上限为模型半径的 `1.3` 倍。

## 文件结构

- `src/skinning.js`：骨架、调色板、LBS/DQS CPU 实现与零权重回退。
- `src/shaders.js`：GPU 双路径顶点着色器和误差热图着色。
- `src/renderer.js`：WebGL2 视口、轨迹、探针环与骨骼诊断线。
- `src/models.js`：程序化分节圆柱、肘关节、共享权重和孤立顶点。
- `src/analysis.js`：截面积、轨迹、符号稳定性与绑定姿态证明。
- `src/main.js`：场景切换、播放、`±q` 操作和实时 UI。
- `tests/`：数学、绑定姿态、符号、零权重和截面积回归测试。
