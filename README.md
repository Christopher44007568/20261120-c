# 20261120-c

## 相干光线排序与打包实验 (raysort)

迷你 BVH 路径追踪器 + 组相联 LRU 缓存模拟器，验证"相似方向光线重排后
批量求交"对缓存命中率 / 带宽 / 每帧求交耗时的收益。

### 构建与运行

```sh
make run
```

### 方法

- 场景：64x64 高度场地形（8192 三角形，BVH 节点 ~256KB + 三角形
  ~640KB，远大于 32KB 模拟缓存），三角形材质随机为漫反射/镜面。
- 排序键（`src/sort_key.h`）：粗原点格(4bit/轴) → 方向八面体编码
  Morton(10bit/轴) → 细原点格(6bit/轴)，原点局部性与方向局部性兼顾。
- 缓存模型：32KB / 64B 行 / 8 路 LRU（`src/cache_sim.h`），BVH 遍历中
  每次节点/三角形访问记一次缓存访问，带宽 = 未命中数 x 64B。
- 实验：A 主光线排序前后；B 路径追踪二次光线（漫反射+镜面混合批次）
  排序前后；C 漫反射/镜面分流各自排序，验证混合方向不抵消局部性收益。

### 典型结果（192x192 主光线，10 帧平均）

| 配置 | 未命中 | 命中率 | 带宽 | ms/帧 | 相邻方向余弦 |
|---|---|---|---|---|---|
| 主光线 未排序 | 158,026 | 86.9% | 9.65MB | ~7.1 | +0.9965 |
| 主光线 已排序 | 63,150 | 94.8% | 3.85MB | ~6.5 | +0.9999 |
| 二次光线混合 未排序 | 353,820 | 68.0% | 21.60MB | ~10.7 | +0.4562 |
| 二次光线混合 已排序 | 197,350 | 82.2% | 12.05MB | ~9.8 | +0.7689 |
| 漫反射流 单独排序 | 141,179 | 75.6% | 8.62MB | ~6.1 | +0.6603 |
| 镜面流 单独排序 | 60,892 | 88.5% | 3.72MB | ~4.0 | +0.8142 |
| 分流+排序 合并 | 202,068 | 81.7% | 12.33MB | ~10.0 | +0.7376 |

结论：排序使主光线未命中 -60%、二次光线 -44%，带宽同比例下降，每帧
求交加速约 1.1x；相邻光线方向余弦与命中率同步提升。混合批次排序
(197k) 与分流排序 (202k) 差距仅 ~2%，说明方向差异未抵消局部性收益；
镜面流因反射瓣更集中，局部性上限明显高于漫反射流。
