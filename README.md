# 程序化星系、星云与 L-system 树木生成

纯 Python（numpy + Pillow）的程序化生成管线：用 3D 值噪声/fBm 与粒子混合
生成旋涡星系与彩色星云，并实现 L-system 递归树木。所有结果带量化指标与
确定性回归测试，无需 GPU。

## 运行方式

```bash
# 首次：创建虚拟环境并安装 numpy / pillow
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run_all.sh            # 或分步执行：
.venv/bin/python src/run_galaxy.py          # 星系频率扫描 + 多视角
.venv/bin/python src/run_trees.py           # L-system 深度与规则对比
.venv/bin/python src/make_contact_sheets.py # 拼图
.venv/bin/python src/verify.py              # 回归校验
```

## 模块结构

- `src/noise.py`：可播种的 3D 值噪声与 fBm（多倍频、lacunarity、gain）。
- `src/galaxy.py`：粒子星系。对数式螺旋角 + fBm 角向扰动 + 高斯臂散射，
  核球/旋臂分色（核心暖黄、臂上蓝白亮星）。
- `src/renderer.py`：加法混合 CPU 光栅化。星云体积精灵为第 1 批次，
  星点软光斑为第 2 批次；星云颜色由三路独立 fBm 场映射到红/青/紫。
- `src/camera.py`：透视相机、look-at、轨道视角与投影。
- `src/lsystem.py` / `src/tree_render.py`：L-system 规则展开、3D 海龟
  解释（`[ ]` 压栈、`+ - & ^` 四向旋转）与投影渲染。
- `src/metrics.py`：旋臂对齐度、角向离散、臂褶皱度、径向分布 TVD。

## 星点数量与绘制批次

每个星系固定 **12,000 颗星 + 2,600 个星云采样点**（同一随机种子，可复现）。
所有视角与频率下绘制批次恒为 **2**：

| 项目 | 数量 |
| --- | --- |
| 星点粒子 | 12,000 |
| 星云精灵 | 2,600 |
| 绘制批次 | 2（星云批次 + 星点批次） |
| 每帧 draw calls | 14,600（2,600 星云精灵 + 12,000 星点） |
| 可见星点（4 个视角） | 12,000 / 12,000 / 12,000 / 12,000 |

完整数据见 `artifacts/galaxy_report.json`。

## 噪声频率与旋臂形态的关系

固定种子与星点数，只改变 fBm 基础频率，得到 4 组对照（俯视渲染见
`artifacts/contact_frequency.png`）：

| 噪声频率 | 旋臂对齐度 | 臂褶皱度 | 径向分布 TVD（对 1.0 基线） |
| --- | --- | --- | --- |
| 0.5 | 0.716 | 0.0347 | 0.0002 |
| 1.0 | 0.834 | 0.0339 | 0.0000 |
| 2.0 | 0.829 | 0.0534 | 0.0002 |
| 4.0 | 0.853 | 0.0812 | 0.0001 |

结论：

- **频率升高 → 扰动空间尺度变小**，旋臂中心线从平滑连续的宽带逐渐变成
  多褶皱、碎化、团块状的细臂；臂褶皱度（中心线二阶差分 RMS）单调上升，
  0.0347 → 0.0534 → 0.0812，约 2.3 倍。
- **低频（0.5）** 噪声相关长度覆盖整条旋臂，表现为大尺度弯曲与弥漫星云带，
  对齐度下降到 0.716（臂更宽更松散）。
- **高频（4.0）** 扰动只在局部作用，整体螺旋走向保持，边缘出现毛刺和
  恒星形成结，对齐度反而回升至 0.853。
- **星点径向分布稳定**：各频率相对基线的总变差距离 TVD ≤ 0.0002，
  说明频率只改变形态褶皱，不改变星点的径向密度结构，分布稳定。

## 多视角结构稳定性

同一星系从 4 个轨道视角渲染（`artifacts/contact_views.png`）：
俯视 88°、斜视 32°、侧视 4°、侧旋 55°。

- 可见星点变异系数 **CV = 0.0**（四视角均为 12,000 颗，无裁剪丢失）。
- 投影质心最大漂移 **5.84 px / 720 px（0.8%）**，星系始终居中。
- 俯视可见三条旋臂与核球；侧视收敛为带核球增亮的薄盘，验证了
  `z` 向厚度衰减模型；斜视同时保留旋臂缠绕与盘厚度信息。

## L-system 递归深度

固定规则 `F → FF+[+F-F-F]-[-F+F+F]`、转角 22.5°，深度 1–4
（`artifacts/contact_tree_depth.png`，数据见 `artifacts/tree_report.json`）：

| 深度 | 枝条段数 | 叶端数 | 句子长度 | 树高 |
| --- | --- | --- | --- | --- |
| 1 | 8 | 2 | 20 | 2.67 |
| 2 | 64 | 18 | 172 | 6.55 |
| 3 | 512 | 146 | 1,388 | 13.74 |
| 4 | 4,096 | 1,170 | 11,116 | 30.36 |

每增加一层，枝条段数严格乘以 **8**（该规则每个 F 产生 8 个 F），
`verify.py` 对该指数增长做断言，确认递归参数有效且可控。

## 规则参数决定枝条分布与密度

深度固定为 4，替换规则与转角（`artifacts/contact_tree_rules.png`）：

| 规则集 | 转角 | 枝条段数 | 叶端数 | 叶密度（叶端/冠幅体积） | 形态 |
| --- | --- | --- | --- | --- | --- |
| `FF[+F][-F][&F][^F]` | 28° | 1,296 | 1,036 | 0.658 | 浓密、四向分枝、冠幅宽 |
| `FF+[+F-F-F]-[-F+F+F]` | 22.5° | 4,096 | 1,170 | 0.029 | 展开、分层延展、体积大 |
| `F[+F]F[-F][F]` | 16° | 625 | 468 | 0.621 | 窄瘦、直立、分枝稀疏 |

分枝符号数量决定每节分枝基数（2/3/4 叉），转角决定水平展开程度，
两者共同决定冠幅体积与叶密度；量化差异与渲染形态一致，确认规则参数
直接控制枝条分布与密度。
