# HELIO / BUS — 日照多层布线观测台

一个无第三方运行时依赖的交互式页面：太阳高度角与方位角连续驱动天空颜色、
环境光和投影方向；同一块四层载板上展示 6 条已校验的正交线路与 6 个过孔。

## 运行

```bash
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080

npm test                    # 16 个 Node 内置测试
node scripts/export-report.js
```

页面也支持直接打开 `index.html`：光源、路由与时间模块均以普通脚本加载。

## 光照模型

- 观测点按 31.23°N / 121.47°E、赤纬 0° 计算太阳高度角与方位角；
- 天空调色板在高度角 `−35° … 89°` 上分段线性插值，天顶、地平线、环境光和
  太阳颜色连续变化；方位角还提供一个连续的暖色权重，因此同一高度角的黎明与
  日落不会得到完全相同的天空；
- 直射照度由大气质量与太阳可见度平滑得到，并同时输出总照度 `lx` 与
  `W/m²` 辐照度；
- 阴影方位严格取太阳方位 `+180°`，投影长度和组件偏移随太阳高度变化；
- 夜间以月亮补光，LED 与线路辉光提高；24 小时在午夜无颜色接缝。

默认渲染时刻为 17:45（高度角 3.206°、方位角 268.054°、总照度
1,878.7 lx、辐照度 11.664 W/m²）。正午为 58.770° / 180.000° /
96,377.7 lx / 879.9 W/m²。

### 日落连续性

17:00–19:30 以 1 分钟步长采样 151 点：

- 相邻天空颜色最大变化 `6 / 255`（阈值 8）；
- 总照度最大相对跳变 `15.223%`（阈值 30%）；
- 太阳 → 阴影方位误差 `0.000000°`；
- 24 小时循环在 `23:59 → 00:00` 的颜色差为 `0`。

### 时间与渲染

页面使用 `1/60 s` 固定仿真步长，并由 `requestAnimationFrame` 读取权威时钟后
渲染。真实帧间隔被限制在 `100 ms` 内，光照值不按帧累加，因此掉帧不会产生
颜色跳变。默认 6 分钟/秒：60 FPS 时每帧推进 0.10 仿真分钟，完整 24 小时
需要 240 秒真实时间。

## 四层线路

`src/routing.js` 使用带层间代价的 A* 在 24 × 16 × 4 网格上顺序布线，并对已占用
单元、过孔位置和端点进行约束。固定场景结果：

- 6/6 网络布通，同层交叉 `0`；交叉下界为 `0`，因此已达到全局最少；
- 6 个不重复过孔，全部位于通孔路径上、避开 6 个组件障碍且互不碰撞；
- 平面长度 70 格，过孔加权总长度 124（过孔代价 9）。

| 网络 | 过孔 XY | 层间 |
| --- | --- | --- |
| VCC | (13, 03) | TOP → IN1 |
| LED | (01, 08) | TOP → BOT |
| XTAL | (09, 13) | TOP → IN2 |
| SDA | (08, 05) | TOP → IN2 |
| SCL | (08, 09) | TOP → IN1 |
| MOSI | (17, 12) | TOP → IN2 |

## 产物

- `artifacts/report.json`：光照、循环、时间关系、路由和全部检查；
- `artifacts/validation.txt`：可读的结果摘要；
- `artifacts/sunset-samples.csv`：1 分钟日落采样；
- `artifacts/lighting-cycle.csv`：10 分钟全天采样；
- `artifacts/routing.csv`：各网络长度与层序列；
- `artifacts/observatory.svg`：无浏览器依赖的 17:45 场景；
- `artifacts/preview-*.png`：日落、金色时刻、正午、夜间界面截图。

## 代码结构

- `src/lighting.js`：太阳位置、调色板、照度、日落/全天验证；
- `src/routing.js`：四层 A* 布线、过孔提取、交叉与避障验证；
- `src/time.js`：固定步长时钟和“时间 → 帧”换算；
- `src/app.js`：Canvas 场景、HUD、时间轴与交互；
- `tests/*.test.js`：太阳、日落、循环、线路、过孔和时间推进测试。
