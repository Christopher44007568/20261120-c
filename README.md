# Stencil Shadow Volume Lab

WebGL2 模板阴影体实验台，重点验证：

- 闭合网格的轮廓边挤出、近端/远端封帽与 Z-Fail 模板计数。
- 开放网格的逐三角形闭合棱柱封帽。
- 相机位于阴影体内、以及相机穿越阴影体边界时的模板奇偶性。
- 阴影体三角形数、屏幕填充率、模板计数直方图。
- 细长物体上模板阴影与 512/1024/2048 阴影贴图的边缘锐度对比。

## 运行

```bash
npm install
npm start
```

打开 `http://localhost:4173`。页面不需要构建步骤。

```bash
npm test        # 无头 Chromium + WebGL2 自动验证
npm run capture # 重新生成 artifacts/final 下的截图、掩码和 results.json
```

无头环境使用 SwiftShader。不同 GPU 的像素数量和填充覆盖率可能有少量差异，但拓扑、模板奇偶性和边缘优劣关系不变。

## 实现

闭合网格：

1. 用与光源方向的点积找出受光三角形。
2. 对受光三角形边集合做反向边抵消，得到轮廓边。
3. 沿光反方向挤出轮廓边约 26 个世界单位。
4. 添加受光近端封帽和反向绕序的远端封帽。

开放网格没有可靠的外法线轮廓，因此对每个源三角形生成一个独立三角棱柱：3 个侧面、1 个近端盖、1 个远端盖。棱柱之间的重叠会产生大于 1 的模板计数，判断阴影时仍使用 `stencil != 0`。

模板通道使用 `DEPTH24_STENCIL8`。Z-Fail 模式下，正面减一、背面加一，执行深度失败写入。最终只把阴影叠加到可见地面，避免把投影体本身再次压暗。

## 验证结果

结构验证中，封帽后的闭合球、开放面和细长板体积边界边均为 `0`。关闭封帽后，闭合球体积出现 `204` 条边界边，开放面棱柱出现 `64` 条边界边。开放网格的封帽体积在拓扑合并统计中会有重叠非流形边，这是逐三角形棱柱重叠的正常结果；每个棱柱自身仍是封闭的。

| 场景 | 体积三角形 | 封帽三角形 | 填充率 | 模板非零像素 | 与阴影贴图掩码差异 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 闭合球 / 体外 / Z-Fail | 6,348 | 6,144 | 14.54% | 18,391 | 0.012% |
| 闭合球 / 体内 / Z-Fail | 6,348 | 6,144 | 100% | 459,669 | 0.178% |
| 闭合球 / 体内 / Z-Pass | 6,348 | 6,144 | 100% | 135,531 | 99.822% |
| 开放面 / 体外 / 封帽 | 960 | 240 | 20.91% | 18,295 | 0.023% |
| 开放面 / 体内 / 封帽 | 960 | 240 | 100% | 525,913 | 0.123% |
| 开放面 / 体内 / 无封帽 | 720 | 0 | 100% | 515,360 | 1.897% |
| 细长板 / 体外 / Z-Fail | 24 | 12 | 32.02% | 5,737 | — |

填充率定义为 960×620 画面中被阴影体三角形覆盖的唯一像素比例。开放面无封帽时模板非零覆盖仍在，但远端点会漏光，体内视角下掩码差异从 `0.123%` 增至 `1.897%`，对应截图中的亮色缺口。

相机在体内时，Z-Pass 的模板区域发生整体翻转；体内 Z-Pass 与阴影贴图掩码差异达到 `99.822%`，说明近裁剪面交点被漏计。Z-Fail 保持 `+1` 非零计数，差异回到 `0.178%`。

穿越验证：

| 进度 | 相机位置 | 是否在体内 | 模板非零像素 | 填充率 |
| --- | --- | --- | ---: | ---: |
| 0.64 | `(2.116, 1.458, 0.811)` | 否 | 385,112 | 91.10% |
| 0.86 | `(1.805, 1.392, 0.426)` | 是 | 439,358 | 100% |

穿越后阴影与阴影贴图掩码差异为 `0.102%`，阴影区域保持正确。

## 细长物体边缘

指标为阴影两条边缘逐行提取后，对直线做最小二乘拟合的 RMS 残差，单位为像素，越低越锐利。

| 阴影贴图分辨率 | Stencil RMS | Shadow Map RMS | Stencil 提升 |
| ---: | ---: | ---: | ---: |
| 512² | 0.288 | 1.956 | 85.3% |
| 1024² | 0.288 | 1.005 | 71.3% |
| 2048² | 0.288 | 0.586 | 50.8% |

细长板阴影在模板通道中单像素采样，不经过光源深度图离散化，因此三种分辨率下边缘都比阴影贴图更锐利。
