# 正交电路/管道走线与噪声频谱分析（纯标准库实现）

本项目在没有第三方科学计算库的环境下，仅使用 Python 3 标准库完成：

- 按端点与障碍生成**正交（曼哈顿）走线**，双信号层自动选择层间过孔；
- A* 寻路 + 占用软代价 + 拆线重绕（单网热点重绕、成对协同重绕），使交叉最少；
- 多层线路**过孔位置提取与校验**（相邻层、无重复、不压障碍）；
- 输出每条网络与整板的线路长度、过孔数、加权总长度与交叉数；
- 参数扫描量化网格规模、障碍密度、网络数对布线密度的影响；
- 手写 radix-2 FFT 实现 Welch 功率谱，对比白/粉/棕红三种噪声并检测高频伪影。

## 目录结构

- `layout/geometry.py`：板框、网格、障碍与端点数据结构及合法性检查
- `layout/astar.py`：层内正交移动 + 层间过孔的 A* 搜索
- `layout/router.py`：多网络排序、拆线重绕、交叉统计、过孔校验
- `layout/fft.py`：迭代 radix-2 FFT/IFFT
- `layout/noise.py`：三种噪声生成、Welch PSD、斜率拟合与伪影检验
- `layout/sweep.py`：随机板参数扫描与聚合
- `layout/svg.py`、`layout/viz.py`：纯 SVG 渲染（走线图、频谱图、密度柱状图）
- `layout/scenario.py`：固定演示板（18×15，2 层，5 个障碍，5 条网络）
- `tests/test_pipeline.py`：9 个 `unittest` 用例

## 运行

```bash
python3 -m layout          # 生成 artifacts/ 下全部报告与 SVG
python3 -m unittest discover -s tests
```

## 演示板结果（固定随机种子，可复现）

- 5 条网络全部布通，`crossings = 0`，正交走线全部绕开障碍；
- 平面长度合计 115 格，过孔 4 个，过孔单位代价 5，加权总长度 135；
- 过孔校验通过：每个过孔仅跨相邻层、坐标不压障碍、无重复过孔；
- 过孔位置（网络, 单元格, 起始层→目标层）：
  `clk (16,13) 0→1`、`sense (17,5) 0→1`、`data (15,3) 0→1`、`pwr (14,14) 0→1`。

## 参数对密度的影响（54 组随机板，每组 3 个种子）

- 网络数 4→12 时，平均单元密度上升约 +0.124，是密度的主导因素，并开始出现交叉；
- 障碍率 5%→25% 时，密度上升约 +0.029，走线被迫绕行，高密度小网格出现残余交叉；
- 网格 16→24（容量增大）时，密度下降约 -0.065，交叉显著减少；
- 全部 54 组布通率 100%，平均交叉 0.148；残余交叉经硬封禁核验为两层板几何约束下的
  局部最优，而非算法缺陷。

## 噪声频谱（N=4096，Hann 窗 512，相同种子与单位方差）

- 白噪声斜率实测 -0.00（理论 0），粉噪声 -1.00（理论 -1）；
- 棕红噪声低频段实测 -1.96（理论 -2）；全频带 -1.76 与离散传递函数
  `1/(4 sin²(πf))` 的理论弯曲 -1.756 一致，并非伪影；
- 高频段（0.30–0.50 奈奎斯特区）能量比均低于校准阈值 1.25，确认无高频上冲伪影；
  注入 0.42 fs 单音的对照实验可被检测器成功捕获（见测试用例）。

## 产物

- `artifacts/report.json`：路由、过孔、扫描效应、频谱检验的完整结构化结果
- `artifacts/routing.svg`：分层走线图（灰块为障碍，同心圆为过孔，圆点为端点）
- `artifacts/spectra.svg`：三种噪声 log-log Welch 频谱与 0/-1/-2 斜率参考线
- `artifacts/density.svg`、`artifacts/density_sweep.csv`、`artifacts/density_summary.json`
- `artifacts/*_preview.png`：由 `tools/` 下纯标准库光栅化器生成的 PNG 预览
  （环境无浏览器/图像库时仍可直接查看，SVG 为矢量正式产物）

环境中 `pip`/`venv` 不可用且无 `numpy`，因此 FFT、PSD 与图表均为手写标准库实现；
FFT 正确性由直接 DFT 对拍测试保证（误差 < 1e-12）。
