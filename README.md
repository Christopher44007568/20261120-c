# 20261120-c：基于泊松方程的点云表面重建

用屏蔽泊松重建（Screened Poisson Surface Reconstruction, Kazhdan & Hoppe 2013）
从带方向法线的点云重建平滑三角网格，并系统评估：

- 法线方向不一致对重建误差的影响；
- 法线一致化（MST 切平面传播）后的误差下降；
- 不同高斯噪声强度下重建表面的平滑性与鲁棒性；
- 每个重建结果的顶点数、三角形数与重建耗时。

## 方法原理

泊松重建把表面视为实体区域指示函数 `χ` 的等值面。有向点云的法线定义
采样向量场 `V`，要求 `∇χ ≈ V`。对该变分问题应用散度算子后得到
屏蔽泊松方程：

```
( Δ - λ ) χ = div V
```

其中屏蔽项 `λχ` 把等值面拉向原始采样点。Open3D 在自适应八叉树上用
多重网格求解该方程，再对标量场提取 iso-value=0 的等值面（Marching Cubes
类方法），输出三角网格。由于求解的是全局连续场，局部噪声被积分平滑，
因此泊松重建本身对噪声具有鲁棒性。

处理流程：

1. 在球面/环面上均匀采样，并叠加三维高斯噪声模拟测量误差；
2. PCA 局部切平面估计法线（符号方向随机）；
3. 随机翻转 35% 法线，制造方向不一致；
4. 最近邻图 + 最小生成树传播，做法线一致化；
5. 分别对一致化前/后的点云做泊松重建并计时；
6. 计算 Chamfer、RMSE、P95、Hausdorff、平滑度与网格拓扑指标。

  surfaces.py        # 球面/环面采样、解析真值法线、高斯噪声

## 指标定义

- 法线一致率：与解析真值法线同向的比例（消除全局符号歧义后取值 `max(p,1-p)`）；
- Chamfer：点云→网格与网格→点云最近邻平均距离的对称均值；
- RMSE / P95：输入点到重建网格距离的均方根与 95 分位；
- 平滑度：顶点法线与近邻法线夹角均值（度，越低越平滑）、边长变异系数；
- 网格质量：边界边、非流形边数量与水密性。

## 主要结论（详见 `artifacts/report.txt`）

- 法线一致化后一致率从约 50% 提升到 100%；
- 噪声球 Chamfer 误差由 0.0378 降到 0.0227（约 -40%），噪声环面由
  0.0326 降到 0.0219（约 -33%），RMSE 同步下降；
- 噪声强度 σ 从 0 增至 0.04（球半径的 4%）时，误差近似线性平滑增长，
  无突变或重建失败，验证泊松重建对噪声鲁棒；
- 一致化后网格内部非流形边为 0；边界边来自八叉树外围与密度裁剪区域；
- 单次八叉树深度 8 的重建耗时约 0.7–1.0 秒，顶点数约 1.4 万–3.1 万。
