逐步复现验收

浏览器 + 命令行双路径

  1. 启动npm start，打开 http://127.0.0.1:8080；状态条应显示“输入合法”。
  2. 看形状固定 α=0.12，比较 RECT 与 DISK 的方/圆高光；MC 图的颗粒是有限样本噪声。
  3. 加样本将 spp 从 4 提到 128，观察 RECT/DISK 的相对 L1 下降、σ 缩小且高光轮廓趋近解析图。
  4. 查连续看粗糙度渐变条：高光形状平滑伸缩；断点 α=0.14/0.32/0.58 处连续跳变应小于 1%。
  5. 读曲线LTC 矩阵 a/b/c/d 曲线无台阶；红色最近邻量化为反例，应产生明显跳变。
  6. 验输入点击“非水密”样例，应报告 4 条边界边、χ=1；重新载入合法样例恢复 PASS。
  7. 跑回归npm test 覆盖解析/采样误差、连续性、方向分布与网格门禁；npm run validate 生成 artifacts。
