# 球面坐标与噪声频率的映射关系

## 1. 球面坐标 → 3D 方向

等距柱状（equirectangular）网格上每个纹素中心对应一对经纬度
`(lon, lat)`，映射为单位球面上的 3D 方向向量：

```
p(lon, lat) = (cos lat · cos lon,  sin lat,  cos lat · sin lon)
```

关键性质（无缝的根本原因）：

- `p(lon + 360°, lat) = p(lon, lat)` —— 经度 0°/360° 是同一条子午线，
  噪声值天然一致，无需任何接缝混合；
- `p(lon, ±90°) = (0, ±1, 0)` 与经度无关 —— 极点在 3D 中是**一个点**，
  整行纹素自动取同一值，不存在极点奇异性。

## 2. 3D 噪声采样

噪声场是 3D 位置的纯函数 `F(p)`（梯度噪声 + fBm 分形叠加）：

```
height(lon, lat) = Σ_k  a_k · N(p(lon, lat) · f_k)
  f_k = f0 · L^k      （第 k 个倍频程频率，L = lacunarity = 2）
  a_k = a0 · G^k      （第 k 个倍频程振幅，G = gain = 0.5）
```

本项目参数（`src/planet_terrain.py`）：大陆 `f0 = 1.8`、6 个倍频程；
山脊 `f0 = 3.4`、5 个倍频程（ridged fBm）；细节层 `f0 = 7.2`。

## 3. 频率 → 空间尺度换算

噪声频率 `f`（单位：周期/半径）对应球面角尺度与线尺度（R 为星球半径）：

```
角尺度  θ ≈ 1 / f            （弧度，一个噪声晶格的张角）
线尺度  s = R · θ = R / f
```

| 层       | 倍频程 k | 频率 f_k | 角尺度     | 线尺度 (R = 6371 km) |
|----------|---------|---------|-----------|----------------------|
| 大陆     | 0       | 1.8     | 31.8°     | ≈ 3540 km            |
| 大陆     | 5       | 57.6    | 0.99°     | ≈ 111 km             |
| 山脊     | 0       | 3.4     | 16.9°     | ≈ 1870 km            |
| 山脊     | 4       | 54.4    | 1.05°     | ≈ 117 km             |
| 细节     | 3       | 57.6    | 0.99°     | ≈ 111 km             |

## 4. 频率 → 纹理分辨率（Nyquist）

等距柱状网格 `W × H = 2048 × 1024`，赤道上纹素角宽
`Δlon = 360°/2048 ≈ 0.176°`。要不失真地解析频率 `f`，每个晶格至少
需要 2 个纹素：

```
f_max(赤道) ≈ W / (4π) ≈ 163 周期/半径
```

最高实际频率 57.6 远小于 163，故当前分辨率对噪声场是过采样的。

纬度 `lat` 处经向纹素的物理间距按 `cos(lat)` 收缩（80° 处仅为赤道的
17%）。对 **3D 噪声**这只是采样变密，场本身不变——所以极地不拉伸；
对 **2D UV 噪声**则意味着同一 u 跨度对应物理距离 `cos(lat)` 倍，
纹理被压缩 `1/cos(lat)` 倍（80° 处约 5.8 倍，89° 处约 57 倍）——这正
是对照实验 E 中极地梯度 RMS 为赤道 49.8 倍的原因。

## 5. 极区补充纹理映射（方位等距投影）

等距柱状图在极点退化（整行纹素塌缩为一个点），因此 `|lat| ≥ 60°`
的区域额外提供极地帽纹理（`src/polar_caps.py`，512×512）：

```
像素 (x, y) → 归一化半径 r、方位角 ψ = atan2(y, x)
距极点角距  ρ = r · 30°
北帽: lat = 90° − ρ,  lon = ψ        南帽: lat = −90° + ρ, lon = ψ
再代入 p(lon, lat) 采样同一个 3D 噪声场
```

帽纹理在 `lat = ±60°` 处与主图重叠衔接；验证（报告 F 节）：
中心像素与精确极点值差 ≈ 2e-3（像素离散化量级）、边界环与主图
RMS 差 ≈ 6e-3、方位角环绕缝隙仅为内部步长的 5–14% —— 无极点挤压、
无接缝。
